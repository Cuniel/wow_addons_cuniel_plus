# Cuniel_plus

魔兽世界正式服的独立界面增强插件，主要配合 ShestakUI 使用。

当前插件版本：**0.3.21**（模拟验证通过，真实游戏效果待复测）。

## 安装

从 [GitHub Releases](https://github.com/Cuniel/wow_addons_cuniel_plus/releases) 下载带版本号的安装包，将 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，再 `/reload`。输入 `/cuniel` 或 `/cplus` 打开设置。无需清空 WTF 或角色缓存。

部位品质：`/cuniel` → “文字与显示” → “装备部位”。灰/白/绿默认关闭，蓝色及以上默认开启；时光徽章等非装备没有部位文字。设置账号共用，字号仍可单独调整。

## 功能

数字格式、FPS、背包位置、职业色角色物品数量、战团存放过滤、装备部位、装等提示和常用窗口 ESC 兼容。各模块可单独开关。使用和历史限制见 [插件说明](Cuniel_plus/README.md)。ESC 兼容不能解除战斗中的保护限制。

## 验证与自动发布

技术栈：WoW 正式服 Lua/UI API；Python 3.12（CI）+ Lupa Lua 5.1 模拟测试。无后端、数据库、运行时 MCP 或 Node 依赖。配置主要账号共享，聊天初始化/备份按角色；自动售卖复用 ShestakUI 当前角色设置，数量为已采集缓存。

源码入口 Core.lua、Options.lua 和 Modules 位于 `Cuniel_plus/`；`tests/` 为模拟脚本，`tools/` 为校验/打包，`release-notes/` 为逐版发布正文。当前源码 0.3.21 不等于已完成真实游戏验证，Git 基准见交接。
