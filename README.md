# Cuniel_plus

魔兽世界正式服的独立界面增强插件，主要配合 ShestakUI 使用。

当前插件版本：**0.3.17**。

## 开发规则与规格

后续开发者和 AI 请先阅读 [AGENTS.md](AGENTS.md) 和 [产品规格 docs/SPEC.md](docs/SPEC.md)；界面与交互规划见 [UI/UX PRD](docs/PRD.md)。SPEC 记录已确认规则，PRD 区分已有需求和待确认设计；未确认或尚未实现的事项单独列出。规格/说明更新不改变当前插件版本或要求重新安装。

## 安装

从 [GitHub Releases](https://github.com/Cuniel/wow_addons_cuniel_plus/releases) 下载带版本号的安装包，将 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，再 `/reload`。输入 `/cuniel` 或 `/cplus` 打开设置。无需清空 WTF 或角色缓存。

部位品质：`/cplus` → “显示装备部位文字”旁的“品质”。灰/白/绿默认关闭，蓝色及以上默认开启；时光徽章等非装备没有部位文字。设置账号共用，字号仍可单独调整。

## 功能

数字格式、FPS、背包位置、职业色角色物品数量、战团存放过滤、装备部位、装等提示和常用窗口 ESC 兼容。各模块可单独开关。使用和历史限制见 [插件说明](Cuniel_plus/README.md)。ESC 兼容不能解除战斗中的保护限制。

## 验证与自动发布

安装 Python 和 `requirements-dev.txt` 的依赖，运行 `tests/test_*.py`；执行 `python tools/package.py` 打包。发布前必须更新 TOC 版本、README 本次更新及对应 `release-notes/v版本.md`。

提交到 `main` 后，Actions 先验证代码和说明，再打包并创建带中文更新内容的 Release；同时同步仓库已维护的历史 Release 说明。已有版本只更新说明，不覆盖其安装包。缺少说明文件会阻止发布，避免只剩提交比较链接。
