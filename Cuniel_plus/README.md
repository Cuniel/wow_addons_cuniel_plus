# 0.3.3 大版本分类、跨页整理与银行兼容调整

整理规则：
1. 先按游戏物品数据中的大版本排序（新到旧；无法识别的放在最后）。
2. 每个大版本内部依次为材料、消耗品、未绑定 BoE 装备、其他装备、背包、配方、任务物品、其他。
3. 材料依照游戏子类分组，例如附魔、皮革、布料、矿石、草药；多专业共用的材料按游戏分类，不根据名称猜测配方用途。
4. 同子类按名称排列，同名再按品质、装等、物品 ID 与堆叠数排列。已绑定的原 BoE 不归入可交易 BoE 组。
5. 战团已开放且可操作的标签页合并为一个整理空间，会跨标签页移动。普通银行不与战团互相搬运；材料包、特殊用途包仍独立。
6. Cuniel 工具条上的“整”：左键物品靠后、空格在前；右键物品靠前、空格在后。两种方向内部的分类顺序相同。再次点击停止。跟随 Bagnon 的格子显示方向。Bagnon 自带扫帚不受这套规则控制。

银行后右键失效：历史 BugGrabber 中存在 Bagnon 的 UseContainerItem 拦截，以及 ShestakUI AutoOpens 自动开包的拦截，但不是本次复现的实时日志，不能由此确认单一根因。新版移除了 GetExtraButtons 方法替换和主动调用 Bagnon Layout，改用窗口下方独立工具条，避免将功能嵌入 Bagnon 的物品布局路径。未修改 Bagnon/ShestakUI 文件，也没有改写游戏的物品使用函数。此为兼容调整，不保证解决所有受保护操作问题。

## 使用

将整个 Cuniel_plus 文件夹放入 `_retail_/Interface/AddOns/`，重启游戏并启用。
输入 `/cuniel` 或 `/cplus` 打开设置，也可通过游戏设置的插件分类打开。

- 数字：万／亿、K／M／B、跟随 ShestakUI。修改后在对应数值刷新时生效。

## 范围与兼容性

### Bagnon 增强

本版本针对本机 Bagnon 12.1.3 接口编写，不修改 Bagnon 或 ShestakUI 文件。按钮在运行时加入顶部工具栏。

- “整”：独立实现 ShestakUI 风格的排序键，分类后物品靠后、空格在前。与 ShestakUI 原整理模块并非同一实例；材料包分组，银行各标签页单独整理，不跨个人银行与战团银行搬动。不等同于暴雪自动合堆。
- “存”：左键调用与 ShestakUI 相同的 C_Bank.AutoDepositItemsIntoBank(Account)。右键切换“包含制作材料”，使用游戏共用设置 bankAutoDepositReagents。只处理游戏允许自动存入的物品，不转移金币。
- 银行按钮必须在当前角色、实际可操作的银行中使用；离线缓存不可操作。整理在战斗、窗口关闭或仓库切换时停止。再次点击“整”可停止。

当前识别：截图中的 GearInsight 加载及群宣传、RaiderIO 数据过期提醒、地下堡助手加载及模式信息、地瓜加载提示和牧羊少年上线宣传。
并非无差别过滤所有插件。插件在 Cuniel_plus 加载前已经输出的内容不会删除；未知提示保留，可后续增加匹配规则。正常聊天、拾取、任务消息不作为过滤目标。

只覆盖 ShestakUI 的 ShortValue 统一数字接口，不影响 Details、Plater 或所有游戏数字。
FPS 不依赖 ShestakUI。数字接口缺失或被其他插件接管时，在设置中提示，不强行覆盖。

未在实际游戏内完成银行物品操作、战斗、受限制数值和视觉验收；模拟测试不能代替游戏实测。
