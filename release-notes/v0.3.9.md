# Cuniel_plus 0.3.9

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 新增装备部位字号设置（8–24，默认11），已有文字即时更新。
- ESC 兼容覆盖世界地图及角色主窗口（包括声望、货币分页）。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.9.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。
