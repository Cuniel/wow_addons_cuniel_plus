# Cuniel_plus 0.3.13

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 补上现代飞行地图 FlightMapFrame 与旧式路线图 TaxiFrame 的 ESC 兼容。
- 新增 /cplusesc，显示加载版本、兼容开关、战斗状态和当前窗口登记状态，并保存诊断报告。
- 本次解决飞行地图遗漏；战斗中的天赋关闭限制不属于窗口登记问题。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.13.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。

注意：ESC 登记不能绕过战斗中的受保护关闭限制，仍需脱战后关闭。
