# Cuniel_plus 0.3.20

本地测试包，未提交、推送或发布到 GitHub。

## 适用版本

国服正式服开发基线 12.1.5.70448 / Interface 120105。2026-10-21 读取 Windows Wow.exe 的 FileVersion 与 ProductVersion；TOC 声明 120100/120105。没有真实 Mac/Windows 游戏验收记录。

## 本次更新

- Details 不再用屏幕百分比决定上沿和左沿，改为按实际框体坐标划定区域：目标框/相邻头像下方、实际技能栏右侧、小地图左侧双列小图标预留区、底部信息线之上。
- 有足够可读宽度时伤害在左、治疗在右等宽并排；不足则伤害在下、治疗在上等宽堆叠，保留伤害 60%/治疗 40% 高度预算。总高度均不超过目标框下沿，扣除标题/皮肤后按完整行裁剪，不缩字号或删除统计数据。
- 右侧按实际收集图标尺寸预留两列及间距，底部使用 BottomPanel 实际位置。目标隐藏仍读取布局锚点，避免突然向上扩展；必要坐标未知/受限制时等待，不猜测。
- 技能栏编辑器模式优先测量实际按钮/栏位，避免无形的十二格锚点额外占宽；锚点变化合并重新计算，保留安全战斗纠偏、有限冲突停止和关闭后的会话位置/尺寸恢复。
- 保持 0.3.19 的字体补偿及其他配置、缓存和备份；不修改上游插件文件或自动发布。

## 安装与设置

将 Cuniel_plus-0.3.20.zip 内的 Cuniel_plus 覆盖到正式服 _retail_/Interface/AddOns/，然后 /reload。进入 `/cuniel → 兼容与诊断`，可点击“立即检查并重新排列”。旧设置保留，不清空 WTF。战斗中的受保护窗口等待脱战，关闭后恢复当前会话原位置与尺寸，不承诺跨重载还原。

## 验证与限制

模拟覆盖实测边界、宽屏并排/窄屏堆叠等宽、总高度限制、双列图标预留、底部线、完整行、障碍/无空间、隐藏/受限目标、不同有效缩放、锚点变化、编辑器占位框、重复应用稳定性、拖动与战斗纠偏/保护、会话恢复。模拟不等于游戏实测；自定义框架名称、吸附组、保护布局与其他插件位置覆盖仍需真实客户端复测。
