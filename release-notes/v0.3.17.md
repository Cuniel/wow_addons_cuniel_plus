# Cuniel_plus 0.3.17

## 适用版本

开发依据为本机国服正式服 **12.1.5.70448**，接口 **120105**；2026-10-19 核对 `.build.info` active wow 产品与 `_retail_/Wow.exe` FileVersion。TOC 声明 120100 / 120105；其他地区未做游戏实测。

## 本次更新

- 新增默认开启的中文聊天标签初始化，参考 Ciaoasher 的聊天分类，在每个启用插件的角色首次登录后创建“公会、密语、团队”。
- 首次应用先备份并清理原有永久自定义标签，保留综合、战斗记录和内置语音；临时会话不清理，避免旧英文/中文自定义标签重复。
- 公会页包含公会、官员、公会成就；密语页包含游戏内和战网密语；团队页包含小队、团队、团队警告和副本频道。综合原有消息和已加入的频道保持原设置。
- 每角色只初始化一次；重复登录、重载与切地图不反复删除重建。账号共用开关，初始化标记和原配置备份按角色保存。
- 增加主动重建、恢复原标签并停用当前角色自动配置的入口。备份不含聊天内容和输入历史；关闭开关不会删除现有标签。
- 战斗中延后，接口缺失或临时会话占满窗口时不修改现有配置；中断不标记成功，也不无限重试。
- 明确中文适应性的规划重点为排版与数字单位，保留 DoT、HoT 等术语；本版未扩大数字格式覆盖，也未重构整个设置窗口。

## 安装与设置

下载 `Cuniel_plus-0.3.17.zip`，将 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。无需清空 WTF。

默认会在登录后初始化当前角色的聊天标签，并替换其永久自定义标签。设置入口：`/cuniel` 或 `/cplus` → 右下“聊天标签页”。可关闭账号自动配置，或恢复当前角色的首次备份；恢复不包含已关闭窗口的聊天历史。

已核对参考角色的聊天分类和当前客户端版本；Lua 5.1 模拟覆盖清理去重、重复登录、消息分类、内置/临时窗口保留、跨角色、备份恢复、战斗延后、接口缺失与失败恢复。未完成真实游戏环境实测，尤其需登录后检查实际消息路由及其他聊天插件的相互影响。
