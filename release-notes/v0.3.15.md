# Cuniel_plus 0.3.15

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 物品统计默认隐藏炉石、达拉然炉石、要塞炉石和灰色垃圾。
- 默认扣除已穿在身上的装备数量；同款物品放在背包或银行仍统计。
- 新增独立过滤面板：可开关默认规则、选择隐藏任务物品，并填写物品 ID 排除名单。
- 保留绑定装备，缓存不删除；过滤只影响 Cuniel_plus 新增统计，不隐藏 ShestakUI 自带数量行。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.15.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。
