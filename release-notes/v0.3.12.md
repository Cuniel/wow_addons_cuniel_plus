# Cuniel_plus 0.3.12

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 扩展 ESC 兼容名单：天赋/专精/法术书、专业、收藏、冒险指南、成就、观察、地下城查找器、好友、社区和宏窗口。
- 登录、进入世界和插件按需加载后检查窗口登记，避免漏掉晚加载的窗口。
- 重复登记、关闭开关和原窗口脚本保留均有模拟验证；不能解除战斗保护。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.12.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。

注意：ESC 登记不能绕过战斗中的受保护关闭限制，仍需脱战后关闭。
