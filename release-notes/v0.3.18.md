# Cuniel_plus 0.3.18

## 适用版本

开发依据：国服正式服 **12.1.5.70448**，接口 **120105**。2026-10-19 核对本机 `_retail_/Wow.exe` FileVersion；此前 `.build.info` active wow 产品一致。TOC 声明 120100 / 120105。Windows/Mac 使用同一份布局代码，但本版尚未完成真实游戏跨平台实测。

## 本次更新

- `/cuniel`、`/cplus` 改为分类配置界面：总览、背包与银行、物品提示、文字与显示、兼容与诊断。文字与显示分为数字格式、帧数显示和装备部位三个子页。
- 优先沿用已加载的 ShestakUI 深色皮肤、按钮与复选框；长页面内部滚动，窗口可拖动、可用 ESC 关闭，较小可用区域自动适应窗口边界。保留现有设置和全部原功能入口。
- 装备部位开关、字号、所有品质集中在同页，提供文字预览。设计稿里的搜索、图标样例和恢复本页默认尚未实现，不作为本版功能宣传。
- 新增默认开启的 Details 自动避让：检查首个可见伤害与首个可见治疗窗口，在重叠、越界或遮挡已识别区域时尝试并排；横向空间不足则尝试上下排列。
- 按窗口有效缩放统一坐标，计入标题和皮肤边距；避开小地图、可识别动作条、玩家/目标框架及其他可见统计窗。位置正常时保持，不缩小字体、不隐藏统计内容；没有安全位置时提示手动留出空间。
- 登录、窗口显示/尺寸变化、分辨率/UI 缩放变化时合并检查；战斗中延后，拖动中不强行移动。可关闭或主动重新排列；关闭可恢复当前会话中由本模块修改前的位置，不承诺跨重载还原。
- Mac 字体适配按用户要求暂缓；本版不调整 Windows/Mac 字体。数字覆盖扩展与完整数值模式仍是优先待实现需求，没有算作本版已交付。

## 安装与设置

下载 `Cuniel_plus-0.3.18.zip`，将 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。无需清空 WTF 或重新配置现有选项。

输入 `/cuniel` 查看新界面；Details 在“兼容与诊断”顶部，可切换自动避让或点击“立即检查并重新排列”。伤害与治疗两个窗口须已显示；战斗中等待脱战。只有一个窗口或缺少兼容接口时不强行调整。现有自定义吸附组、其他插件覆盖位置及所有屏幕布局尚未全部验证。

## 验证范围

Lua 5.1 模拟覆盖宽/窄屏并排与上下布局、障碍避让、有效缩放换算、正常布局保留、无可用空间、战斗延后、缺失接口及关闭恢复；配置界面验证导航、页面显示隔离、旧设置保留、重要子面板入口、品质切换与小屏幕边界。模拟通过不等于实际游戏已验证，需进一步检查 Windows/Mac 的真实窗口和 ShestakUI 皮肤效果。
