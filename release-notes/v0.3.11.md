# Cuniel_plus 0.3.11

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 将外置装等黑色页脚合并为现有鼠标提示框内部一行。
- 沿用 ShestakUI 黄色“物品等级”标题、相对装等颜色和一位小数。
- 保留行引用并限制主动布局次数，避免重复追加及递归刷新。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.11.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。
