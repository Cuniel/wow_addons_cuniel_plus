# Cuniel_plus 0.3.14

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 新增提示框“战团物品统计（缓存）”：职业颜色角色名、持有数量和独立的战团银行数量。
- 独立记录背包、材料包、身上装备及已读取的个人银行；战团银行只计一次，不依赖持续启用 Bagnon。
- 运行时存在 BrotherBags 数据时导入历史缓存；离线角色需登录、银行需打开以更新，邮箱和公会银行不统计。
- 对未知/受保护数据保留可用旧缓存，限制每次提示框追加一次统计。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.14.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。
