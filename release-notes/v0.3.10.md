# Cuniel_plus 0.3.10

## 适用版本

TOC 声明适用于魔兽世界正式服 **12.1.0 / 12.1.5**（接口 120100 / 120105）。该历史发布未单独记录精确客户端构建号，不能将新版本的客户端构建号视为本版本的实测记录。

## 本次更新

- 新增“修复装等重复：切换 Cuniel_plus 并重载”按钮。
- 关闭当前 ShestakUI 保存配置中的平均装等功能，使用独立装等显示，避免等待提示无限追加。
- 检查战斗状态和保存配置；修复按钮不修改 ShestakUI 源文件。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.10.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。
