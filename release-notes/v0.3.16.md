# Cuniel_plus 0.3.16

## 适用版本

当前对应国服正式服 **12.1.5（构建 70448）**，接口 **120105**。来源：本机 .build.info 的 active wow 产品及 Wow.exe FileVersion，读取于 2026-10-18。TOC 同时声明 120100 / 120105；本次开发验证基于当前 12.1.5，非全功能游戏实测。

## 本次更新

- 装备部位新增完整品质列表：灰、白、绿、蓝、紫、橙、神器、传家宝、时光徽章（特殊品质），可逐项开关。
- 默认灰/白/绿不显示部位，蓝色及以上显示；已有用户升级后也应用这一首次新增默认规则。
- 保留部位字号设置；品质修改即时刷新，品质未知或受保护时暂不显示，资料到达后重试。
- README 的本次更新按版本单独编写，记录客户端 12.1.5.70448 和接口 120105；历史记录移至 CHANGELOG.md。
- Release 改用仓库内逐版维护的中文说明；补齐 0.3.9–0.3.15 已发布版本，后续缺少对应说明将阻止发布。

## 安装与设置

下载此 Release 的 `Cuniel_plus-0.3.16.zip`，将其中 `Cuniel_plus` 文件夹覆盖到 `_retail_/Interface/AddOns/`，然后 `/reload`。输入 `/cplus` 打开设置。无需清空 WTF 或已有角色缓存。

部位品质入口：`/cplus` → “显示装备部位文字”旁的“品质”。非可穿戴物品没有部位，即使对应品质勾选也不会显示。
