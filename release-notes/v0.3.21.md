# Cuniel_plus 0.3.21

本版本包含自 0.3.18 后积累的字体与布局改进；模拟验证通过，真实游戏效果仍需复测。

## 适用版本

国服正式服开发基线 12.1.5.70448 / Interface 120105，2026-10-21 核对 Windows Wow.exe；TOC 声明 120100/120105。真实 Mac/Windows 游戏尚需复测。

## 本次更新

- 包含 0.3.19/0.3.20 改进：Mac 高分辨率小字最低字号补偿，以及依据目标框、技能栏、小地图双图标预留和底部线测量 Details 可用区域；按完整行减少高度，不缩小统计文字。受保护操作等待脱战，非保护统计窗提供有限次数的位置纠偏。
- 公会、密语、团队三个聊天标签标题默认 14 号，Windows/Mac 共用，保留原字体/描边，不修改聊天正文或综合/战斗记录等普通标签。已有角色不重建聊天窗口，也不覆盖首次备份。
- 标签字号在“文字与显示 → 字体可读性”独立可调 10–20；鼠标悬停后仍保持，与通用小字补偿互不争抢。关闭聊天功能或恢复原标签时恢复当前会话的原字号，战斗中延后。
- Details 以可用区域最右边为基准，治疗在右，伤害以 2 UI 单位间距贴其左侧，保留可读宽度而不是拉宽铺满空白；宽度不足时等宽上下堆叠且右边缘对齐，延续 6:4 高度预算。
- 继续遵守目标框下沿、技能栏右侧、小地图双图标预留及底部线边界；不为右对齐越过障碍，不改变字体补偿、统计数据或上游源文件。

## 安装与设置

无目标时预留目标、相邻头像和目标的目标，修正头像位于血条右侧有间距时漏算下沿；新增选中/清除目标前后位置、尺寸与模式不变的回归测试。

覆盖 Cuniel_plus-0.3.21.zip 中的 Cuniel_plus 到正式服 _retail_/Interface/AddOns/ 后 /reload，不清空 WTF。“文字与显示 → 字体可读性”调整标签标题字号，“兼容与诊断”主动重排 Details。

## 验证范围

已知外部问题：错误记录仍有 ShestakUI 污染环境下任务追踪冷却/地图小组件访问受限制数值，以及 VoidcoreHelper 物品提示参数错误。本版未修复或隐藏这些问题，不能承诺黄色“错误过多”提示消失。

模拟覆盖独立 14 号默认、已有角色无重建、悬停重设、聊天正文保留、平台独立、通用字体补偿共存、开关/恢复与战斗延后，以及统计双窗右锚、紧邻间距、四边界、宽窄切换和稳定性。模拟不等于真实游戏通过；仍需用户实际复测。
